# Backend

This folder will contain the backend implementation for the Invoice AI Project.

## 📌 Purpose

The backend will serve as the communication layer between:

- The frontend user interface
- The AI processing modules in `ai_core/`

It will handle:

- Uploading invoice images
- Managing processing jobs
- Returning structured data
- Providing basic data analytics via API

## 🚧 Notes

This folder is currently a placeholder. The backend logic will be added as the project evolves.
